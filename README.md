# Sputnik Link (SatLink) — NeoForge 1.21.1

Мод спутниковой связи:
- **satlink:dish** — антенна. ПКМ: канал +1, Shift+ПКМ: канал −1 (1–16).
- **satlink:ground_station** — станция. ПКМ: статус (канал / число антенн / сигнал 0–15). Shift+ПКМ: сменить канал.
- Сигнал компаратора = сила сигнала (число загруженных антенн на том же канале, макс. 15).
- Работает в обычном мире и на структурах Sable (sub-levels).

Сборка: GitHub Actions → artifact `sputnik-link-jar` → `satlink-0.1.0.jar`.
